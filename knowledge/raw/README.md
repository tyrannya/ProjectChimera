# Raw external research intake

Store unsynthesized external material here: source notes, paper metadata, repository observations, copied URLs, issue/postmortem notes, and rough hypotheses.

This area is **NON-AUTHORITATIVE** and may contain contradictions, stale claims, or low-confidence notes.

Before a claim is promoted into `knowledge/wiki/`, verify the source and record limitations. Before any claim affects ProjectChimera governance/science, use the project's normal plan/preregistration/review process.
