# ProjectChimera External Knowledge Vault

Status: **NON-AUTHORITATIVE RESEARCH MEMORY**.

This directory is designed to be opened as an Obsidian vault or read directly by Claude Code as an external research/second-brain layer.

It is intentionally separate in meaning from ProjectChimera's authoritative scientific and engineering state.

## Authority firewall

Nothing in `knowledge/` may override or establish:

- current Git branch/head/base;
- PR or merge state;
- active roadmap adoption;
- preregistration state/hash;
- evidence eligibility;
- scientific results/verdicts;
- Aegis/live risk state;
- safety boundaries;
- whether a task is complete.

For those questions, reconstruct repository truth from Git, frozen contracts, executable guards, manifests, artifacts, tests and CI.

If a knowledge note conflicts with repository truth, **repository truth wins**.

## Structure

```text
knowledge/
├── raw/                 incoming external notes and source captures
├── wiki/                curated linked research notes
│   └── master-index.md  graph entry point
└── output/              derived external reports/syntheses
```

Recommended future wiki domains include:

- futures/perpetuals;
- scalping;
- spot;
- market microstructure;
- multi-timeframe research;
- execution/accounting;
- risk/safety;
- statistical validation;
- failure modes;
- external tools/repositories.

## Note quality

For important external claims, prefer notes that record:

- claim/question;
- primary source URL;
- source type;
- checked date;
- evidence strength;
- applicability/limitations;
- related notes.

Do not silently convert a knowledge-vault hypothesis into a ProjectChimera scientific rule. Promotion requires an explicit project governance/research step.
